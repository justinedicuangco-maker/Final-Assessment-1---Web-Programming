HTML & CSS Quick Reference Guide

A simple reference guide for commonly used HTML tags and CSS properties.

HTML Tags

<html>

Root element of an HTML document.

<head>

Contains metadata and links.

<title>

Sets the browser tab title.

<body>

Contains all visible content.

<h1> - <h6>

Headings from largest to smallest.

<h1>Main Heading</h1>
<h2>Sub Heading</h2>

<p>

Used for paragraphs of text.

<a>

Creates clickable links.

<a href="https://example.com">Visit</a>

<img>

Displays images on a webpage.

<img src="image.jpg" alt="Image">

<div>

Container used to group elements.

<footer>

Bottom section of a webpage.

<footer>End of page</footer>

CSS Properties

color

Changes text color.

background-color

Sets background color.

font-size

Changes text size.

margin

Adds space outside elements.

padding

Adds space inside elements.

border

Adds borders around elements.

text-align

Aligns text left, center, or right.

display

Controls layout behavior.
